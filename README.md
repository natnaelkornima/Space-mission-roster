# Astronaut Crew Management System

A JavaScript project that manages an astronaut crew roster for a space mission. It provides functionality for adding crew members, swapping positions, filtering EVA-eligible astronauts, sorting by priority, dividing crew members into groups, and printing crew summaries.

## Features

- **Add Crew Members:** Add astronauts to the crew while preventing duplicate IDs.
- **Swap Crew Members:** Swap the positions of two astronauts without modifying the original array.
- **Priority Sorting:** Sort astronauts by priority in descending order using the Bubble Sort algorithm.
- **EVA-Eligible Crew:** Filter astronauts based on their EVA eligibility.
- **Crew Chunking:** Divide astronauts into smaller groups of a specified size.
- **Crew Summary:** Display astronaut names sorted by priority.
